# ✅ To-Do List

A modern and responsive To-Do List web application built using HTML, CSS, and JavaScript.

This project was created to practice JavaScript fundamentals, DOM manipulation, events, arrays, objects, localStorage, and building a real interactive web application.

## 🚀 Features

- ➕ Add new tasks
- ✏️ Edit tasks
- 🗑️ Delete tasks
- ✔️ Mark tasks as completed
- 🔄 Toggle completed/uncompleted tasks
- 🔍 Filter tasks by All, Active, and Completed
- 📊 Task counters
- 🧹 Clear completed tasks
- 🗑️ Clear all tasks
- ⌨️ Add tasks using the Enter key
- 💾 Tasks are saved using LocalStorage
- 📱 Responsive design
- 🎨 Neo-Brutalist UI
